# Changelog

All notable repository changes will be recorded here. Dates refer to repository preparation, not public app releases.

## [0.1.0] - 2026-11-23

### Added

- Two Xcode iOS application projects in one shared workspace.
- SwiftUI WebView implementations of Lock In Gram and Lock In Tube.
- App icon asset catalogs, GitHub Actions simulator-build workflow, and static repository checks.
- Installation, architecture, privacy, limitations and test documentation.

### Known limitations

- Live website filtering remains best-effort and sensitive to third-party markup changes.
- Xcode build verification and end-to-end testing on additional devices are still required.
