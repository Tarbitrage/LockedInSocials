# Security policy

## Supported versions

This repository is an experimental prototype, not a security-maintained production release. No support guarantees or security response SLA are provided.

## Reporting a vulnerability

If the repository has **GitHub Private Vulnerability Reporting** enabled, use its **Security > Report a vulnerability** flow. Otherwise, open a brief issue **without exploit steps, credentials, account data, cookies, or personal messages** and request a private contact channel.

Avoid testing on another person's account or device without their explicit authorization.

## Scope

Security concerns include credential exposure, unsafe external navigation, third-party script injection, storage of website sessions, unsafe permission requests and unintentional collection of private data.
